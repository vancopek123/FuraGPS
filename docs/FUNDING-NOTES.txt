FURA GPS — OPTIONAL SUPPORT

Official support page: https://ko-fi.com/furagps

Fura GPS is free to use. Contributions through Ko-fi are completely optional.
Support helps with navigation improvements, Coach tools, translations and
testing on more phones and tablets. Every contribution is appreciated.

The GitHub Sponsor button is configured in .github/FUNDING.yml. The README
includes a support button linking directly to the same Ko-fi page.

Source attribution and map-data licensing details remain in the project's
THIRD-PARTY-NOTICES.txt and CREDITS.txt. Support is for Fura GPS development.
